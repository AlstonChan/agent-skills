# Open questions

Facts the guide needs that nobody has confirmed yet. A fact that is not confirmed is left out of
the guide, not guessed and not marked; it is written down here instead. This file is never
rendered.

Write each item under `## Open` as one numbered item: the question (quote the label, path or
message in doubt), where it came from (the code, history or memory that raised it), and what will
be written for each answer, naming the section it lands in. When an answer arrives, write it into
its chapter and delete the item; when none is left, put back `None yet.`
