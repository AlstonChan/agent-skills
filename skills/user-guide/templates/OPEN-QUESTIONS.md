# Open questions

Facts the guide needs that nobody has confirmed yet. A fact that is not confirmed is left out of
the guide, not guessed and not marked; it is written down here instead. This file is never
rendered.

Write each item as: where in the guide it belongs, the question (quote the label, path or message
in doubt), where it was met in the code, and what answer settles it. When an answer arrives, write
it into its chapter and delete the item.
