# Getting Started {#sec-getting-started}

This chapter takes you from opening [[APP_NAME]] to finishing your first task. Read it once; the
chapters after it describe each part of the program in detail, and the appendices at the back
explain its terms and what to do when something goes wrong (@sec-troubleshooting).

## Start the program

1. Open **[[APP_NAME]]** from the Start menu or its desktop shortcut.
2. If a sign-in window appears, enter your user name and password and press **Log In**.
3. Wait for the main window to open (@fig-main-window).

![The main window of [[APP_NAME]] as it first opens.](images/01-main-window.png){#fig-main-window width=90%}

## The main window

The main window is split into the parts listed below. Each one has its own chapter.

| Part | What it is for |
| :--- | :--- |
| **Menu bar** | Opens the settings and the other windows of the program (@sec-settings). |
| **[[AREA_NAME]]** | The area you work in most. It is explained in @sec-[[AREA_ID]]. |
| **Status bar** | Shows what the program is doing and any message for you. |

## Your first task

1. Choose **[[AREA_NAME]]** in the menu bar.
2. Pick the item you want to work on from the list.
3. Press **Open**. The item appears in the main window.
