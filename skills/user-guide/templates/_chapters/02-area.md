The [[AREA_NAME]] area is where you find, open and organise your work in [[APP_NAME]]. This
chapter shows what the area looks like, what each control does, and how to carry out its common
tasks.

![The [[AREA_NAME]] area when it first opens.](images/02-[[AREA_ID]]-overview.png){#fig-[[AREA_ID]]-overview width=90%}

## What you can do here

| Control | What it does |
| :--- | :--- |
| **Search** | Narrows the list to the items that match what you type. |
| **Open** | Opens the selected item in the main window. |
| **Delete** | Removes the selected item. Asks you to confirm first. |

: The controls of the [[AREA_NAME]] area {#tbl-[[AREA_ID]]-controls}

## Open an item

1. Choose **[[AREA_NAME]]** in the menu bar.
2. Type part of the name in **Search**. The list shrinks as you type.
3. Select the item you want.
4. Press **Open**.

## Remove an item

1. Select the item in the list.
2. Press **Delete**.
3. Press **Yes** in the confirmation window.

::: {.callout-important}

## Removing cannot be undone

Once you confirm, the item is gone. If you are not sure, leave it where it is.
:::
